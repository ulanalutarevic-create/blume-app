Как запустить сайт blume* (verdura-app)
========================================

1. Открой Терминал (Terminal).

2. Перейди в папку проекта:
   cd "/Users/ulalutarevic/Desktop/УПВеб — копия/5-7/verdura-app"

   Или открой эту папку в Finder, затем:
   клик правой кнопкой по папке → «Новый терминал в папке»
   (Services / New Terminal at Folder).

3. Если зависимости ещё не установлены (первый запуск):
   npm install

4. Запусти сайт:
   npm run dev

5. Открой в браузере:
   Фронтенд:  http://localhost:5173/
   API:       http://127.0.0.1:3010

6. Чтобы остановить сайт — в Терминале нажми Ctrl + C.

Важно:
- Окно Терминала не закрывай, пока сайт работает.
- Нужны установленые Node.js и npm.
